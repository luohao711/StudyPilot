# StudyPilot 数据模型说明

来源：本人根据 backend/app/repository/db.py 的建表语句整理，2026-10-16 更新。
用途：补充实验3 ER 图的文字说明，方便资料问答检索到表结构与关联关系。

## 表结构

### users 用户表
- user_id：主键，自增
- name：用户姓名

### courses 课程表
- course_id：主键，自增
- user_id：外键，指向 users.user_id
- name：课程名称，同一用户下不允许重名（UNIQUE(user_id, name)）
- term：学期
- created_at：创建时间

### exam_goals 考试目标表
- goal_id：主键，自增
- course_id：外键，指向 courses.course_id，一门课程只能有一条考试目标（UNIQUE）
- exam_date：考试日期，格式 YYYY-MM-DD，必须晚于今天
- target_score：目标分数，1—100
- available_minutes：每天可用学习时间，默认 120 分钟
- created_at：创建时间

### knowledge_points 知识点表
- point_id：主键，自增
- course_id：外键，指向 courses.course_id
- name：知识点名称，同一课程下不允许重名（UNIQUE(course_id, name)）
- mastery：掌握度，0—100 的整数，由用户填写或确认后更新
- updated_at：最后更新时间

### study_plans 学习计划表
- plan_id：主键，自增
- course_id：外键，指向 courses.course_id
- status：计划状态，draft（候选）或 confirmed（已确认）
- generator：生成方式，rule_template 表示规则模板生成
- created_at：创建时间
- confirmed_at：用户确认时间

### daily_tasks 每日任务表
- task_id：主键，自增
- plan_id：外键，指向 study_plans.plan_id
- course_id：外键，指向 courses.course_id
- point_id：外键，指向 knowledge_points.point_id，可为空（手工添加的任务可以不对应知识点）
- title：任务标题
- task_date：任务日期，必须早于考试日期
- minutes：预计时长，单位分钟
- status：任务状态，todo 或 done
- note：完成备注
- completed_at：完成时间

## 表之间的关联

- 一个用户拥有多门课程：users 1—N courses。
- 一门课程有一条考试目标：courses 1—1 exam_goals。
- 一门课程有多个知识点：courses 1—N knowledge_points。
- 一门课程有多份学习计划，最新一份为当前计划：courses 1—N study_plans。
- 一份计划包含多个每日任务：study_plans 1—N daily_tasks。
- 一个知识点可以关联多个任务：knowledge_points 1—N daily_tasks（task.point_id 可为空）。

## 数据维护说明

- 建表语句在服务启动时执行，使用 CREATE TABLE IF NOT EXISTS，不会删除已有数据。
- 样例数据放在 backend/seed_data.json，用 python3 -m app.seed 写入，--clear 清空业务数据，--reset 清空后重新写入。
- 数据库文件为 backend/data/studypilot.db，删除该文件后重新启动服务即可重建空库。
